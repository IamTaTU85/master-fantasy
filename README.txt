INSTALACIÓN EN GITHUB PAGES
1. Entra en tu repositorio master-fantasy.
2. Borra el archivo incorrecto llamado "actividad" si no lo necesitas.
3. Pulsa Add file > Upload files.
4. Sube los cinco archivos de esta carpeta SUELTOS, no el ZIP.
5. Pulsa Commit changes.
6. Ve a Settings > Pages y confirma:
   Deploy from a branch / main / root.
7. Espera uno o dos minutos y abre:
   https://iamtatu85.github.io/master-fantasy/

IPHONE
1. Abre la dirección con Safari.
2. Compartir.
3. Añadir a pantalla de inicio.
4. Activa Abrir como app web si aparece.
5. Añadir.

WINDOWS
1. Abre la dirección en Chrome.
2. Menú de Chrome.
3. Instalar MASTER FANTASY PRO.

NOTA
Esta versión guarda datos localmente por dispositivo.
Para sincronización automática entre iPhone y Windows hará falta una base de datos online.
